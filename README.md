# 小小的身影，重叠的内心 (작은 그림자, 겹쳐지는 마음) 한국어 패치

![한국어 패치 적용 타이틀 화면](images/title.jpg)

Steam 비주얼 노벨 **小小的身影，重叠的内心** (Tiny Shadows Interwoven Hearts)의 비공식 한국어 패치입니다.

## 설치

1. [Releases](../../releases)에서 `TinyShadows_KoreanPatch_v*.zip`을 받습니다.
2. 압축 안의 `game` 폴더를 게임 폴더(`TinyShadowsInterwovenHearts.exe`가 있는 폴더)에 덮어씁니다.

## 면책

팬 번역이며 개발사·배급사와 관계가 없습니다. 게임의 권리는 각 권리자에게 있습니다.
